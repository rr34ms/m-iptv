M-IPTV pour Windows

La télévision, les films et les séries sur votre ordinateur, avec une interface moderne et un lecteur avancé.

Télécharger M-IPTV pour Windows

Windows 10 / 11 (64 bits) · dernière version · gratuit, sans compte · toutes les versions

Le téléchargement est libre. Il ne comprend ni abonnement ni licence : pour regarder les contenus, connectez-vous avec un compte M-IPTV disposant d’un abonnement actif (voir les abonnements).

Comment installer

  1. Téléchargez avec le bouton violet.Vous obtenez le fichier M-IPTV-Windows.zip dans « Téléchargements ».
  2. Clic droit sur le fichier → « Extraire tout… » → « Extraire ».Un dossier M-IPTV-Windows s’ouvre.
  3. Double-cliquez sur « Installer M-IPTV », puis attendez le message « C’est installé ! ».Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires » → « Exécuter quand même ». Si le Contrôle intelligent des applications est actif, M-IPTV s’ouvre dans une fenêtre Microsoft Edge, avec les mêmes fonctions.
  4. Connectez-vous avec l’e-mail et le mot de passe de votre compte M-IPTV.Pas encore de compte ? Créez-le ici. Il faut un abonnement actif pour regarder.

Ensuite, M-IPTV s’ouvre avec l’icône du Bureau. Pour la retirer : « Desinstaller M-IPTV » dans le dossier extrait (vos favoris et réglages sont conservés).

Fonctionnalités

  • Chaînes TV en direct, classées par catégories
  • Films et séries, saisons et épisodes
  • Guide TV : maintenant et à suivre
  • Favoris et historique
  • Reprise de lecture des films et séries
  • Recherche intelligente
  • Clean Library : versions d’une même chaîne réunies
  • Choix de la qualité (versions HD, FHD…)
  • Retour en arrière sur le direct
  • Son des flux non compatibles converti automatiquement
  • Télécommande depuis votre smartphone (réseau local, protégée par code)
  • Mode invité protégé par un code
  • Centre de santé et diagnostic de connexion
  • Connexion avec votre compte M-IPTV
