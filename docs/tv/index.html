Connecter un téléviseur

Saisissez le code à 6 chiffres affiché sur le téléviseur (M-IPTV → Compte M-IPTV → « Se connecter avec le téléphone »). Le téléviseur utilisera ensuite votre compte.

Le code est valable 10 minutes et ne sert qu’une fois. N’autorisez que vos propres appareils : chaque téléviseur compte dans le nombre d’appareils de votre abonnement.
